# グローバル Agent 指示

## コミュニケーションと自律性

- 対話・PR・reviewer 向け説明は、別指定がなければ日本語で、結論から簡潔に書く。
- 相談には回答し、変更の依頼では実装・検証まで進める。合意を引き継ぎ、許可済みの作業を再確認しない。
- 結果や範囲を大きく左右する不明点は確認し、それ以外は妥当な仮定で進める。
- 追加指示は、明示的な取消しや目的変更がなければ進行中の依頼へ反映する。
- 上位の安全・実行制約に従い、ユーザーの明示指示を skill の既定方針より優先する。
- 確認や検証不能がある場合は依存する操作を保留し、未完了の範囲を報告する。skill が理由なら該当指示とリンクを示す。

## 開発

- 依頼の完了条件を満たすまで進め、無関係な改善を加えない。検証の追加・再実行は変更の影響と残る懸念に合わせる。
- subagent は実行環境が許し、統合コストに見合う場合に使う。主担当が成果を確認する。
- terraform apply など実インフラへの破壊的操作には対象・操作の許可が必要。原則は PR マージ後とし、マージ前の実行は都度承認を得る。

## Skill の入口

- Git・commit・PR：`chouge-git`
- コード・設定・agent 指示の実装：`implement`
- agent skill のレビュー：`skill-workbench`
- テストのレビュー：`test-writing-style`
- `CHANGES.md`：`chouge-changelog`
- APM：`apm-usage`
